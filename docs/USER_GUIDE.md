# 使用说明

## 1. 启动观察台

```bash
python3 scripts/start_workbench.py --open
```

浏览器打开 `http://127.0.0.1:3000`。

## 2. 选择剧集

1. 在左侧选择项目。
2. 在右侧选择剧集。
3. 进入剧集页后点击九阶段中的任一阶段查看状态和产物。

选择阶段只改变展示，不会改变制作起点。

## 3. 查看产物

- 文档和 Prompt：点击卡片阅读完整文本。
- 图片：点击缩略图查看原图。
- 视频：直接使用真实播放器。
- 空阶段只显示明确的空状态，不会生成假缩略图。

## 4. 添加标注

1. 选择阶段。
2. 先选择“添加建议”或“要求重做”。
3. 选择“整个阶段”或一个具体产物。
4. 输入反馈并提交。

保存后页面会显示待处理数量、重做数量和 revision。标注不会直接触发生成；重做要求会由 Codex 绑定到 Repair Plan，只有新版本生成并完成逐镜与跨镜审查后才会关闭。

产物卡片显示独立资产版本 `vN`。出现旧版本时，可在预览器中切换查看；旧版本不可修改，也不会重新成为活动资产。

## 5. 在 Codex 中继续制作

直接告诉 Codex目标项目、剧集和动作，例如：

- “继续制作雨夜项目的 ep04。”
- “按工作台新增标注重做故事板。”
- “查看婚礼项目 ep01 为什么阻塞。”

Codex 会使用 `scripts/workflow.py` 读取状态和增量标注，再由确定性流程校验与落盘。

只有视频生成需要单独确认；文字与图片制作由当前“继续制作”或“重新生成”请求授权。
