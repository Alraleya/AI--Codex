# 剧本与分镜定稿

## 唯一职责

这是流程中唯一允许完成故事、分镜和视频 Prompt 的阶段。阶段完成后，所有动作、台词、镜头、时长、转场和视频 Prompt 正文都锁定；后续阶段只能生产或绑定资产。

## 用户已提供完整剧本时

若 `creative_brief.provided_script` 已包含完整剧本、分镜或视频 Prompt：

1. `script.md` 必须与用户原文逐字一致；
2. 只按视频 Provider 可提交的“视频生成单元”机械拆分；
3. 不评判或改写动作因果、台词顺序、角色关系、空间方向、道具状态、风格、镜头语法或时长分配；
4. 一个视频生成单元可以包含多个内部剪辑镜头。不得把10秒内的六个1.5秒内部镜头拆成六次视频生成；
5. 只在无法编号、缺少单元时长、单元为空、单元超出 Provider 硬限制，或拆分遗漏原文时阻塞；
6. 非阻塞疑点只能记录，不能触发润色、扩写、重排或“优化”。

### Prompt结构优化模式

当用户明确要求“镜头内容不动、只优化Prompt结构”时，允许进入结构优化模式：

- 剧情、镜头编号、时长、景别、运镜、画面、台词/字幕、动作特效、AI动作重点、负面约束必须逐字保留；
- 只允许调整字段顺序、分组标题、执行顺序表达和模型可读的格式，不得同义改写、合并、删减或补写镜头内容；
- `script.md` 仍必须逐字等于用户原文；
- 该模式只重做 story_design 的 Prompt 产物及其下游绑定，用户指定保留的定妆阶段必须进入 `preserved` 状态，流程走到时跳过，不重置、不调用图片 Provider。

## 用户未提供完整剧本时

在本阶段一次性完成剧本、详细分镜、故事板执行 Prompt 和最终视频 Prompt，并在返回前做一次内部一致性检查。提交成功后同样锁定，后续不得二次创作。

## 输出

故事板模式返回：

- `outline.md`
- `directing.md`
- `script.md`
- `storyboard.md`
- 每个视频生成单元一份 `shotNN_prompt_video.txt`
- 每个需要故事板的单元一份 `shotNN_prompt_storyboard.txt`

对话直通模式不返回 `storyboard.md` 和故事板 Prompt，但仍返回每个视频生成单元的最终 `shotNN_prompt_video.txt`。

同时返回：

- 已解析的 `shot_plan`：这里的 shot 是一次视频生成单元，不是单元内部的剪辑镜头；
- 故事板模式返回已解析的 `storyboard_plan`；对话直通模式返回 `null`。

## 最终视频 Prompt 锁

`shotNN_prompt_video.txt` 是最终提交正文，不是草稿。它必须已经包含用户要求的风格、内部镜头表、动作、台词、字幕、特效、动作重点和负面约束。后续不得重新转写成另一种“模型格式”。

每份最终视频 Prompt 必须使用以下可机器校验的双层结构，不得用“【0—2秒】……”自然语言时间块代替：

```text
视频生成单元 U01｜时长8S｜画幅9:16｜风格：……
按以下内部镜头逐字执行：
U01-01｜0-1.2S｜景别/运镜｜画面动作｜台词或无｜动作特效/空间连续性
U01-02｜1.2-8S｜景别/运镜｜画面动作｜台词或无｜动作特效/空间连续性
字幕：……
[本单元可见角色] 唐玄、孙悟空（无角色时写“无”）
角色与站位锁：……
动作因果锁：……
负面约束：……
```

内部镜头编号必须从 `Uxx-01` 连续递增；时间使用本生成单元内的局部时间，首镜从 0 开始、相邻镜头无缝衔接、末镜精确等于生成单元时长。每条内部分镜恰好包含六个字段，所有字段非空，无对白写“无”。

新产出应写明 `[本单元可见角色]` 闭合名单，以便 `video_binding` 在不改写 Prompt 的前提下提示疑似漏绑或旧绑定。旧Prompt缺少该字段时不在本阶段阻塞，由视频参考绑定阶段低置信推断并记录提示。

不要在正文中写本地路径。参考图需求和实际文件路径由后续资源规划与绑定文件承担。

## 故事板执行锁

`shotNN_prompt_storyboard.txt` 必须直接来自本阶段锁定分镜，声明：

- `[本镜可见角色]`
- `[本镜场景]`
- `[本镜关键道具]`
- `[首帧锁定]`
- `[末帧锁定]`
- `[动作因果锁]`
- `[版式]`
- 与 `storyboard_plan` 完全一致的 P01–Pnn 时间点

这些字段只用于忠实执行已锁定分镜，不得增加新动作或新镜头。

## 最小硬校验

- 视频生成单元编号连续且不重复；
- 每个单元非空并有合法时长；
- 每个最终视频 Prompt 都有与单元一致的 `Uxx` 头、连续 `Uxx-yy` 内部分镜、完整局部时间覆盖和四类执行锁；
- `shot_plan` 总时长正确；
- 故事板版式与时间点合同正确；
- 用户原文保持逐字不变；
- 输出文件数量与视频生成单元数量一致。

除上述机械合同外，不进行第二轮导演审查。
